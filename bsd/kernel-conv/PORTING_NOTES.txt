FreeBSD AVL Tree - Userspace Port Summary
==========================================

Successfully ported the 2025 FreeBSD kernel AVL tree reorganization to userspace.

Key Differences Between 2014 and 2025 Versions:
------------------------------------------------

1. FILE ORGANIZATION:
   2014: Single avl.h with embedded impl structures
   2025: Split into avl.h + avl_impl.h

2. STRUCTURE CHANGES:
   - avl_tree: removed avl_size, added avl_pad
   - avl_node: unchanged (binary compatible)

3. NEW FEATURES:
   - avl_swap() function
   - TREE_ISIGN(), TREE_CMP(), TREE_PCMP() helper macros

4. CODE OPTIMIZATIONS:
   - Child calculation: avl_balance2child[1 + diff] → (diff > 0)
   - Left calculation: avl_balance2child[old_balance + 1] → (old_balance > 0)
   - Structure copy: assignment → memcpy()

5. HEADER CHANGES:
   - sys/avl_impl.h → avl_impl.h (userspace)
   - Added userspace type definitions (ulong_t, boolean_t)
   - Removed kernel-specific macros (EXPORT_SYMBOL, visibility attributes)

Userspace Adaptations Made:
----------------------------

1. Replaced kernel debug macros:
   ASSERT → assert
   ASSERT0(x) → assert((x) == 0)
   ASSERT0P(x) → assert((x) == NULL)
   ASSERT3P(a,op,b) → assert((a) op (b))
   VERIFY → assert

2. Added type definitions:
   typedef uint64_t ulong_t;
   typedef uint8_t boolean_t;
   #define B_TRUE 1
   #define B_FALSE 0

3. Removed kernel-specific code:
   - EXPORT_SYMBOL() macros
   - Module initialization
   - Kernel header dependencies
